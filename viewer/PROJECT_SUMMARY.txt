🚀 HOW TO USE
═══════════════════════════════════════════════════════════════════════════

Installation:
  $ cd new/
  $ pip install -e .
  $ pip install -e ".[dev]"  # With dev tools

Running Tests:
  $ pytest tests/test_gogame.py -v
  $ pytest tests/ --cov=src/cgosview

Running Application:
  $ cgosview                          # Via entry point
  $ python -m cgosview                # Via module
  
Using Game Engine:
  >>> from cgosview.game import GoGame
  >>> game = GoGame(19)
  >>> result = game.make_move("E5")
  >>> print(f"Captures: {result}")
  Captures: 0

Code Quality Checks:
  $ mypy src/cgosview --strict
  $ black --check src/
  $ ruff check src/
