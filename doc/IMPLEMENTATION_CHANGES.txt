USAGE
================================================================================

Basic Usage:
  1. Create/edit "anchors" file with anchor definitions
  2. Create empty trigger file "set_anchor_players"
  3. Server automatically updates and deletes trigger file
  4. Check logs or database for verification

Configuration (optional):
  anchor_players_trigger_file: "set_anchor_players"
  anchor_players_data_file: "anchors"
  anchor_check_enabled: true

File Format (anchors file):
  # Comments start with #
  PlayerName 1234
  AlphaGo 3400
  Leela 3350

Safety:
  • Updates only when no games in progress
  • Atomic transactions (all-or-nothing)
  • Trigger file preserved on error
  • Automatic retry every ~15 seconds
